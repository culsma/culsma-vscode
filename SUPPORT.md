# Support

Use the [culsma-vscode issue tracker](https://github.com/culsma/culsma-vscode/issues)
for:

- missing or incorrect syntax highlighting;
- `.culs` or legacy `.lw` file association problems;
- bracket, quote, or comment configuration problems;
- extension packaging and installation problems.

Use the [Culsma issue tracker](https://github.com/culsma/culsma/issues) for
parser, compiler, runtime, CLI, language-semantics, or conformance issues.

When reporting a highlighting issue, include a minimal Culsma source example,
the extension version, the editor name and version, and the active color theme.
