# Changelog

## 0.4.0

- Establish the standalone Culsma VS Code extension repository.
- Rename the language identifier and TextMate scope from LabWord to Culsma.
- Register `.culs` as the canonical file extension while retaining `.lw`
  compatibility.
- Synchronize current keywords, quantity units, constructors, program
  constructors, container views, and member methods.
- Add automated TextMate grammar tests and standard VSIX packaging.
- Adopt the Culsma Apache-2.0 license and include the Culsma icon and wordmark.
- Include the Orbitron SIL Open Font License attribution used by the wordmark.
- Add Marketplace metadata, support guidance, and a maintainer publishing
  checklist.
- Add a manually approved GitHub Release workflow that rebuilds and verifies an
  existing version tag without storing a publisher PAT.
