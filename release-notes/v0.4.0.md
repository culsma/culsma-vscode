## Culsma Language Support 0.4.0 (Preview)

The first public preview of the official VS Code language support extension
for Culsma.

### Highlights

- Syntax highlighting for canonical `.culs` source files
- Transitional association for legacy `.lw` files
- Current Culsma keywords, quantity units, constructors, program constructors,
  and core operations
- Highlighting for `plate(...)`, container views, and `.partition(...)`
- Bracket matching, automatic closing pairs, and comment toggling
- Apache-2.0 licensing with bundled third-party attribution for the Culsma
  wordmark
- Automated TextMate grammar tests and VSIX packaging checks

### Install

- [Install from the Visual Studio Marketplace](https://marketplace.visualstudio.com/items?itemName=culsma.culsma)
- Or download `culsma-0.4.0.vsix` from the assets below and use
  **Extensions: Install from VSIX...** in VS Code

This preview provides syntax highlighting and editor language configuration.
Completion, diagnostics, formatting, and language-server features are not yet
included.
