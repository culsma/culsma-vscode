## Culsma Language Support 0.4.1

This is the first stable-channel release of the official VS Code language
support extension for Culsma.

### Highlights

- Syntax highlighting for canonical `.culs` source files
- Transitional association for legacy `.lw` files
- Highlighting for current keywords, quantities, constructors, program
  constructors, container views, and core operations
- Context-aware highlighting for named arguments and record-property keys
- Classification highlighting for `kind`, `type`, and `role` fields and their
  unquoted symbol values
- Bracket matching, automatic closing pairs, and comment toggling
- Apache-2.0 licensing and bundled third-party attribution
- Automated TextMate grammar tests and VSIX packaging checks

### Install

- [Install from the Visual Studio Marketplace](https://marketplace.visualstudio.com/items?itemName=culsma.culsma)
- Or download `culsma-0.4.1.vsix` from the assets below and use
  **Extensions: Install from VSIX...** in VS Code

This extension provides syntax highlighting and editor language configuration.
Completion, diagnostics, formatting, and language-server features are not yet
included.
