## Culsma Language Support 0.4.2

This stable update aligns the TextMate grammar with the Culsma 1.0.10 source surface.
It highlights typed enums such as `AgitationMode.TAP` and
`ShakeMotion.ROCK`, material entry selection and replacement, current
contents volume, named tail returns, and electrical current and motion
frequency units.

The grammar also recognizes concentration initialization and reads,
`mg_per_uL`, `ng_per_uL`, and `ug_per_mL` quantities, `print`, environment
oxygen arguments, and scoped `with sep(...)` / `with frac(...)` blocks.

Install the attached VSIX using **Extensions: Install from VSIX...** in VS Code,
or update Culsma Language Support from the Marketplace once available there.
The extension version is independent of the Culsma runtime version; new
language forms require Culsma 1.0.10. This package provides highlighting,
not runtime execution or semantic validation.
